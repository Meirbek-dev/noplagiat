# Использование Vite+, унифицированного инструментария для веба

В этом проекте используется Vite+ - унифицированный инструментарий, построенный поверх Vite, Rolldown, Vitest, tsdown, Oxlint, Oxfmt и Vite Task. Vite+ объединяет управление рантаймами, управление пакетами и фронтенд-инструменты в едином глобальном CLI под названием `vp`. Vite+ - это не то же самое, что Vite: он вызывает Vite через `vp dev` и `vp build`. Выполните `vp help`, чтобы вывести список команд, и `vp <command> --help` - чтобы получить сведения о конкретной команде.

Документация доступна локально в `node_modules/vite-plus/docs` или онлайн на https://viteplus.dev/guide/.

## Встроенные команды и скрипты

`vp <name>` запускает встроенную команду. `vp run <name>` запускает скрипт из `package.json` или задачу из `vite.config.ts`. Скрипты не могут переопределять встроенные команды, поэтому `vp dev` и `vp run dev` могут делать разные вещи. Сначала проверьте `package.json` и `vite.config.ts` и запускайте `vp run <name>`, если в проекте определён скрипт или задача с таким именем.

## Версии инструментов

Выполните `vp toolchain`, чтобы показать версии и связи между ними в активном
выпуске Vite+. Добавьте имя инструмента, чтобы выбрать часть графа. Например,
выполните `vp toolchain vite`. Используйте `--global`, чтобы игнорировать
локальный пакет `vite-plus`. Используйте `vp why <package>`, чтобы показать граф
зависимостей менеджера пакетов.

## Контрольный список проверки

- [ ] Выполняйте `vp install` после получения удалённых изменений и перед началом работы.
- [ ] Выполняйте `vp check` и `vp test`, чтобы отформатировать, проверить линтером, проверить типы и протестировать изменения.
- [ ] Проверьте, есть ли задачи в `vite.config.ts` или скрипты в `package.json`, необходимые для валидации, и запустите их через `vp run <script>`.
- [ ] Если поведение установки, рантайма или менеджера пакетов выглядит неправильно, выполните `vp env doctor` и приложите его вывод при обращении за помощью.
