# ADR-002: k-анонимность, обеспеченная по построению

**Статус:** принято · 2026-08-29

**Контекст:** TZ.md §6.2 требует подавления на стороне сервера (k=5, настраиваемое);
агентная разработка с минимальным человеческим ревью не может опираться на
дисциплину рецензента.

**Решение:** публичные DTO строятся только из `compliance::Screened<T>` -
сырые агрегаты в публичном ответе не компилируются. Комплементарное подавление -
в `compliance::suppress_table()` (todo). Слой-страж ответов проверяет инвариант
как эшелонированная защита. Property-тесты P1–P3 фиксируют семантику.

**Последствия:** подавление невозможно забыть или обойти на уровне отдельного
эндпоинта; фронтенд отрисовывает маркер единственным компонентом `ScreenedValue`.
