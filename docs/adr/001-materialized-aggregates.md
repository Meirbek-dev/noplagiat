# ADR-001: Предагрегированные материализованные представления вместо кеширования на этапе запроса

**Статус:** принято · 2026-08-29

**Контекст:** загрузка дашборда ≤3 с при 50 тыс. строк, показатель должен сохраняться
и при 250 тыс. (TZ.md §7).

**Решение:** пути запросов читают `agg_monthly` (материализованное представление
месячной гранулярности, обновляемое конкурентно после каждой партии ингеста);
таблица фактов на путях запросов не сканируется никогда. Слоя Redis/кеша нет.

**Последствия:** предсказуемый p95 независимо от роста таблицы фактов; исчезает
целый класс ошибок инвалидации кеша; произвольные диапазоны дат переагрегируют
только граничные месяцы из `checks`.
