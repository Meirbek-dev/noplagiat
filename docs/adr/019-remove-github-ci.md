# ADR-019 - Удаление GitHub CI

**Статус:** принято · 09.09.2026

По прямому запросу владельца проекта удалены все workflow GitHub Actions:
проверки исходного кода, сборка и smoke-тест контейнеров, ночной нагрузочный тест.
Это решение заменяет положения ADR-015 о запуске этих проверок в GitHub Actions.

Автоматические проверки на push, pull request и по расписанию в GitHub больше
не выполняются. GitLab CI, локальные команды проверки, тесты и пороги нагрузки
сохраняются. Проверки готовности из AGENTS.md необходимо запускать локально.
