# ADR-005: Внутрипроцессный планировщик вместо внешнего cron

**Статус:** принято · 2026-08-29

**Решение:** ночной ингест и генерация годового отчёта выполняются как фоновые
задачи Tokio внутри серверного бинарника, с единственным одновременным запуском,
обеспеченным advisory-блокировкой Postgres.

**Последствия:** один разворачиваемый артефакт, один поток логов; горизонтальное
масштабирование в дальнейшем не потребует изменений (advisory-блокировка уже
сериализует раннеры).
