# ADR-003: OpenAPI генерируется из Rust; TS-клиент генерируется из OpenAPI

**Статус:** принято · 2026-08-29

**Решение:** Rust-DTO (utoipa) → `contracts/openapi.json`
(`cargo run --bin export-openapi`) → сгенерированный клиент в `apps/web/src/api/`.
Оба артефакта коммитятся и проверяются в CI на расхождение (режим `--check`).
Ручное редактирование любого из них запрещено (инвариант #5 в AGENTS.md).

**Последствия:** бэкенд и фронтенд не могут молча разойтись; бэкенд мержится
первым, фронтенд перегенерирует.
