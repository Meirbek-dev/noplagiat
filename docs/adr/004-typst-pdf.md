# ADR-004: Typst для генерации PDF

**Статус:** принято · 2026-08-29 (добавление зависимости отложено до появления отчётов)

**Решение:** PDF-отчёты (годовая форма Приложение-1, отфильтрованные выгрузки)
рендерятся крейтом `typst` по брендированному шаблону; XLSX - через
`rust_xlsxwriter`. Не печатью из headless-браузера.

**Последствия:** детерминированный вывод, пригодный для снапшот-тестов; никакого
браузера в серверном образе. Зависимость `typst` добавляется, когда `reports`
реализует PDF.
